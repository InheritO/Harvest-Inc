# 수확 주식회사 (Harvest Inc)

**낫 한 자루로 시작해 농기계 군단을 거느리는 농장 방치형 게임**

밭을 가득 채운 작물을 베고, 번 돈으로 예초기와 콤바인을 들이고, 명성을 쌓아 더 큰 밭으로 옮겨 가세요. 농장이 충분히 커지면 과감히 팔고 새 땅을 개척해 더 큰 수확에 도전합니다.

---

## 이런 게임입니다

- **손맛 있는 수확**: 버튼을 연타하거나 작물을 직접 눌러 베어 냅니다. 작물이 휘청이고, 낟알이 튀고, 코인이 솟아오릅니다.
- **알아서 일하는 농기계**: 예초기는 자주 3칸을, 콤바인은 느리지만 한 줄 전체를 시원하게 쓸어 갑니다. 손을 놓아도 농장은 돌아갑니다.
- **골라 가는 밭**: 밀, 벼, 옥수수, 당근, 호박. 밭을 비울 때마다 쌓이는 명성으로 새 밭을 열고, 연 밭은 언제든 오갈 수 있습니다.
- **새 농장 개척**: 지금까지의 농장을 팔고 황금 씨앗을 받습니다. 황금 씨앗으로 산 영구 강화는 몇 번을 다시 시작해도 남습니다.

---

## 플레이 방법

1. **수확** — 아래 수확 버튼을 누르세요. 꾹 누르면 연달아 벱니다. 작물을 직접 눌러도 됩니다.
2. **강화** — 상점에서 낫을 강화하고 농기계를 사세요. 왼쪽 아래 원이 다 차면 농기계가 작동합니다.
3. **밭 이동** — 밭을 모두 비우면 명성(★)을 얻습니다. 위쪽 밭 이름 버튼을 눌러 다음 밭을 여세요.
4. **개척** — 옥수수 밭을 열면 상점에 개척 탭이 생깁니다. 명성을 모아 새 농장을 개척하세요.

## 조작

| 모바일 | PC | 동작 |
|---|---|---|
| 수확 버튼 누르기 | Space | 낫질 (누르고 있으면 연속) |
| 작물 누르기 | 작물 클릭 | 그 작물을 노려 낫질 |
| 설정 버튼 | ESC | 설정 (소리, 저장, 게임 방법, 종료) |

진행은 자동으로 저장됩니다.

## 설치 방법

### PC (Windows)

1. 설치 파일 **`HarvestInc_Setup.exe`** 를 받아 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 개인이 만든 게임이라 서명이 없어서 나오는 안내입니다.
3. 설치 마법사에서 **다음**을 눌러 진행합니다. 바탕화면 바로가기가 필요하면 체크하세요.
4. 설치가 끝나면 시작 메뉴나 바탕화면의 **수확 주식회사**를 실행합니다.

**설치 위치**

| 항목 | 경로 |
|---|---|
| 게임 | `C:\Users\<사용자 이름>\AppData\Local\Programs\수확 주식회사` |
| 저장 데이터 | `C:\Users\<사용자 이름>\AppData\LocalLow\InheritO\Harvest Inc\save.json` |

- 설치 중에 다른 폴더를 고를 수도 있습니다. 관리자 권한으로 설치했다면 `C:\Program Files\수확 주식회사`에 설치됩니다.
- 탐색기 주소창에 `%LOCALAPPDATA%\Programs\수확 주식회사` 를 붙여 넣으면 게임 폴더로 바로 갈 수 있습니다.
- **제거**: Windows 설정 → 앱 → 설치된 앱 → 수확 주식회사 → 제거. 저장 데이터는 남으므로 다시 설치하면 이어서 할 수 있습니다. 완전히 지우려면 저장 데이터 폴더도 삭제하세요.
- **업데이트**: 새 버전의 설치 파일을 실행하면 기존 설치 위에 덮어씁니다. 저장 데이터는 그대로입니다.
- 창모드(세로 화면)로 실행됩니다. 실행 중 **Alt + Enter**로 전체 화면과 창모드를 바꿀 수 있습니다.

### 모바일 (Android)

1. 휴대폰에서 **`HarvestInc.apk`** 파일을 받습니다.
2. 받은 파일을 누르면 **"출처를 알 수 없는 앱"** 설치를 허용할지 묻습니다. **설정**으로 가서 파일을 연 앱(브라우저, 파일 관리자 등)에 **이 출처 허용**을 켭니다.
3. **설치**를 누릅니다. "Play 프로텍트" 경고가 나오면 **세부정보 → 무시하고 설치**를 누릅니다. 스토어를 거치지 않은 앱이라 나오는 안내입니다.
4. 홈 화면의 **수확 주식회사** 아이콘으로 실행합니다.

- **업데이트**: 새 apk를 설치하면 기존 앱 위에 업데이트됩니다. "앱이 설치되지 않았습니다"가 나오면 기존 앱을 지우고 설치하세요. 이 경우 저장 데이터도 지워집니다.
- **제거**: 앱 아이콘을 길게 누르고 → 제거. 저장 데이터도 함께 지워집니다.
- 세로 화면 전용입니다.
