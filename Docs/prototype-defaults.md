# 프로토타입 기본값 (기획서 v0.2 보완)

기획서 v0.2에서 정해지지 않은 규칙을 프로토타입용으로 정한 값이다. 수치는 모두 `Assets/Scripts/Balance.cs` 한 곳에 있다.

## 범위

- 포함: 1~6장 (밭, 작물, 직접 수확, 농기계, 강화), 10장 1순위 연출(도형 + 코드 생성 사운드)
- 제외: 7장 새 농장 개척, 저장/불러오기, 오프라인 보상, 햅틱

## 밭

| 항목 | 기본값 |
|---|---|
| 밭 방향 | 가로 6 × 세로 8, 세로 화면 |
| 작물 체력 | `ceil(1.15^(레벨-1))` — 기획서 그대로 |
| 작물 보상 | `기본가 × 1.12^(레벨-1)`, 소수점 유지. 화면에는 100 미만이면 소수 1자리, 그 이상은 정수, 1000 이상은 K/M/B 표기 |
| 피해, 체력 | 소수(double)로 계산. 체력 바와 판정에 그대로 사용 |
| 작물 교체 시 체력 | 기획서대로 체력은 연속, 보상만 기본가가 바뀜 (벼 L10, 옥수수 L25) |
| 밭 재생성 0.5초 동안 | 농기계 쿨타임이 멈춘다 |

## 직접 수확

| 항목 | 기본값 |
|---|---|
| 수확 버튼 | 누르는 순간 1회. 0.3초 이상 누르고 있으면 초당 4회 반복 |
| 멀티 터치 | 손가락마다 누르는 순간 1회씩 |
| 작물 직접 탭 | **추가 규칙**: 작물을 탭하면 그 작물이 현재 타겟이 되고 낫질 1회 |
| 타겟 | 밭이 생기면 바로 무작위 타겟을 정하고 테두리로 표시. 타겟이 쓰러지면(농기계에 의한 경우 포함) 즉시 무작위로 다음 타겟 |

## 농기계

| 항목 | 기본값 |
|---|---|
| 예초기 3칸 | 기준 칸을 가운데로 한 3칸. 가장자리면 안쪽으로 밀어 항상 3칸 |
| 콤바인 한 줄 | 가로면 6칸, 세로면 8칸 (기획서대로 무작위라 세로가 유리함) |
| 쿨타임 엇갈림 | k번째(0부터) 기체의 첫 대기 시간 = 쿨타임 × (1 − frac(k × 0.618)) |
| 강화 적용 대상 | 피해, 쿨타임, 정밀 조준 모두 해당 종류 전체에 적용. 1대 이상 보유해야 구매 가능 |
| 쿨타임 단축 | 곱연산 0.95^단계 (10단계에 약 −40%). 구매 즉시 남은 대기 시간도 같은 비율로 줄어듦 |
| 정밀 조준 | 살아 있는 작물 수가 가장 많은 경로. 동점이면 무작위 |
| 가격 | 모든 가격은 올림해서 정수 |

## 개발용 단축키 (에디터, 개발 빌드)

| 키 | 기능 |
|---|---|
| Space | 낫질 1회 |
| F1 | 코인 추가 (현재 밭 보상 10판어치, 최소 1,000) |
| F2 | 남은 작물을 모두 수확 (보상 지급, 클리어 처리) |
