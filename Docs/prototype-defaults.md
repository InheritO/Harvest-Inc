# 프로토타입 기본값 (기획서 v0.2 보완)

> 이 내용은 [기획서 v1.0](design-v1.0.md)에 모두 반영되었다. 앞으로는 v1.0을 기준으로 한다.

기획서 v0.2에서 정해지지 않은 규칙을 프로토타입용으로 정한 값이다. 수치는 모두 `Assets/Scripts/Balance.cs` 한 곳에 있다.

## 범위

- 포함: 1~6장 (밭, 작물, 직접 수확, 농기계, 강화), 10장 1순위 연출(도형 + 코드 생성 사운드)
- 포함: 7장 새 농장 개척 (단계별 새 규칙 제외)
- 포함: 저장/불러오기, 데이터 초기화
- 제외: 오프라인 보상, 햅틱

## 저장

| 항목 | 규칙 |
|---|---|
| 파일 | `Application.persistentDataPath/save.json` (Windows 에디터: `%USERPROFILE%\AppData\LocalLow\DefaultCompany\Harvest Inc\save.json`) |
| 자동 저장 | 10초마다, 앱을 내리거나 끌 때(에디터는 Play 정지), 밭을 열 때, 개척할 때 |
| 저장하는 것 | 코인, 이번 판 번 코인, 명성, 낫 강화, 현재 밭, 연 밭, 농기계(대수·강화·정밀 조준), 황금 씨앗, 단계, 최고 기록, 개척 열림 여부, 영구 강화, 저장 시각 |
| 저장하지 않는 것 | 밭의 작물 상태(불러오면 새로 자람), 농기계 쿨타임 진행도(새로 엇갈려 시작) |
| 깨진 파일 | 새 게임으로 시작하고, 깨진 파일은 `save.json.bad`로 남긴다 |
| 데이터 초기화 | 설정 → 데이터 초기화를 두 번 누르면 모든 진행(황금 씨앗, 영구 강화, 단계 포함)을 지우고 처음부터 |

## 밭 이동 (기획 변경: 밭 레벨 → 밭 이동)

밭을 비워도 레벨이 오르지 않는다. 같은 밭이 다시 자라고, 대신 **명성**을 얻는다. 명성으로 다음 밭을 열어 다른 작물이 심어진 밭으로 옮긴다.

| 항목 | 규칙 |
|---|---|
| 밭 난이도 | 밭마다 고정. 같은 밭은 몇 번을 비워도 체력, 보상이 그대로 |
| 명성 | 밭을 **모두 비웠을 때만** 소량 획득 (작물 하나하나에서는 얻지 않음) |
| 밭 열기 | 명성을 써서 다음 밭을 하나씩 순서대로 연다. 열면 바로 그 밭으로 이동 |
| 이동 | 한 번 연 밭은 언제든 무료로 오갈 수 있다 |
| 이동할 때 | 지금 밭의 남은 작물은 사라지고(보상 없음) 0.5초 뒤 새 밭이 자란다 |
| 유지되는 것 | 코인, 명성, 농기계, 모든 강화 |
| 클리어 보너스 | 기존대로 이번 밭 보상 합계의 50% (코인) + 명성 |

| 밭 | 작물 체력 | 작물 1개 보상 | 클리어 명성 | 여는 비용 (명성) |
|---|---|---|---|---|
| 밀 | 1 | 1 | 1 | 처음부터 열림 |
| 벼 | 5 | 4 | 2 | 5 |
| 옥수수 | 25 | 18 | 4 | 20 |
| 당근 | 125 | 75 | 8 | 60 |
| 호박 | 625 | 320 | 16 | 200 |

**수치 설계 의도**
- 체력은 밭마다 ×5, 보상은 ×4 정도라 체력 1당 보상은 위 밭일수록 조금씩 낮다.
- 그래도 위 밭이 유리해지는 이유는 **초과 피해**다. 낫 피해가 10인데 체력 1짜리 밀을 베면 9가 버려진다. 강해질수록 아래 밭에서는 낭비가 커지므로, 자연스럽게 "충분히 강해졌으면 위로 가는 게 이득"이 된다.
- 명성도 클리어 횟수 기준이라, 어느 밭이든 한 번에 베어지는 수준이 되면 명성이 큰 위 밭이 유리하다.
- 이 의도대로 되는지는 플레이로 확인해야 한다. 아래 밭에 머무는 게 계속 이득이면 위 밭 보상이나 명성을 올린다.

## 새 농장 개척 (환생, 기획서 7장을 밭 이동 구조에 맞게 수정)

| 항목 | 규칙 |
|---|---|
| 열리는 조건 | 옥수수 밭(3번째)을 처음 열면 상점에 "개척" 탭이 생긴다. 한 번 열리면 계속 열려 있다. 기획서의 "밭 레벨 25"와 체력이 비슷한 지점 |
| 보상 | 황금 씨앗 = `floor(0.1 × √(이번 판에 번 코인 총량))`. 개척 탭에 항상 미리 표시 |
| 필요 명성 | `30 × 2^(단계-1)` (1단계 30 → 2단계 60 → 3단계 120 …). 명성이 이만큼 있어야 개척할 수 있다. 개척하면 명성은 어차피 0이 되므로 따로 차감하지 않는다 |
| 실행 | 실수 방지로 버튼을 두 번 눌러야 한다 |
| 초기화 | 코인, 명성, 연 밭(밀만 남음), 농기계, 낫·농기계 강화, 이번 판 번 코인 |
| 유지 | 황금 씨앗, 영구 강화, 개척 단계, 최고 기록(가장 멀리 연 밭) |
| 개척 단계 | 1단계에서 시작. 개척할 때마다 +1. 단계마다 작물 체력 ×1.5, 보상 ×2 (기획서 그대로) |
| 명성, 여는 비용 | 단계와 상관없이 같다 |
| 단계별 새 규칙 | 돌(2단계), 잡초(3단계), 황금 작물(4단계)은 **아직 구현하지 않음** |

**영구 강화 (황금 씨앗)** — 가격 = 기본가 × 증가율^단계, 올림

| 이름 | 효과 | 기본가 | 증가율 | 최대 |
|---|---|---|---|---|
| 풍년 | 모든 수확 보상 +25% (더하기) | 1 | ×1.6 | 없음 |
| 명장의 낫 | 낫 피해 +25% (더하기) | 1 | ×1.6 | 없음 |
| 농기계 할인 | 농기계 구매가 ×0.95 (곱하기) | 2 | ×1.8 | 10 |
| 깔끔한 수확 | 클리어 보너스 +25%p (50% → 75% → …) | 1 | ×1.6 | 없음 |
| 물려받은 예초기 | 개척 직후 예초기 1대 보유 | 3 | — | 1 |

## 밭

| 항목 | 기본값 |
|---|---|
| 밭 방향 | 가로 6 × 세로 8, 세로 화면 |
| 피해, 체력, 보상 | 소수(double)로 계산. 화면에는 100 미만이면 소수 1자리, 그 이상은 정수, 1000 이상은 K/M/B 표기 |
| 밭 재생성 0.5초 동안 | 농기계 쿨타임이 멈춘다 (밭 이동 때도 동일) |

## 직접 수확

| 항목 | 기본값 |
|---|---|
| 수확 버튼 | 누르는 순간 1회. 0.3초 이상 누르고 있으면 초당 4회 반복 |
| 멀티 터치 | 손가락마다 누르는 순간 1회씩 |
| 작물 직접 탭 | **추가 규칙**: 작물을 탭하면 그 작물이 현재 타겟이 되고 낫질 1회 |
| 타겟 | 밭이 생기면 바로 무작위 타겟을 정하고 테두리로 표시. 타겟이 쓰러지면(농기계에 의한 경우 포함) 즉시 무작위로 다음 타겟 |

## 농기계

| 항목 | 기본값 |
|---|---|
| 예초기 3칸 | 기준 칸을 가운데로 한 3칸. 가장자리면 안쪽으로 밀어 항상 3칸 |
| 콤바인 한 줄 | 가로면 6칸, 세로면 8칸 (기획서대로 무작위라 세로가 유리함) |
| 쿨타임 엇갈림 | k번째(0부터) 기체의 첫 대기 시간 = 쿨타임 × (1 − frac(k × 0.618)) |
| 강화 적용 대상 | 피해, 쿨타임, 정밀 조준 모두 해당 종류 전체에 적용. 1대 이상 보유해야 구매 가능 |
| 쿨타임 단축 | 곱연산 0.95^단계 (10단계에 약 −40%). 구매 즉시 남은 대기 시간도 같은 비율로 줄어듦 |
| 정밀 조준 | 살아 있는 작물 수가 가장 많은 경로. 동점이면 무작위 |
| 가격 | 모든 가격은 올림해서 정수 |

## PC 단축키 (모든 빌드)

| 키 | 기능 |
|---|---|
| Space | 수확 버튼과 같음 (누르고 있으면 반복) |
| ESC | 게임 방법이 열려 있으면 닫기 → 상점·개척·밭 이동 창이 열려 있으면 닫기 → 아니면 설정 열기/닫기. 타이틀 화면에서는 무시 |

## 개발용 단축키 (에디터, 개발 빌드)

| 키 | 기능 |
|---|---|
| F1 | 코인 추가 (현재 밭 보상 10판어치, 최소 1,000) |
| F2 | 남은 작물을 모두 수확 (보상 지급, 클리어 처리) |

| F4 | 황금 씨앗 +5 |
