# 농작물 수확 게임 기획서 v1.0 — 수확 주식회사 (Harvest Inc.)

2026-11-17 · 프로토타입 기준

직접 낫질과 농기계로 6×8 밭의 작물을 베어 코인을 벌고, 밭을 비울 때 얻는 **명성**으로 더 단단하고 보상이 큰 밭을 연다. 충분히 성장하면 농장을 팔고 **새 농장을 개척**해 영구 강화를 얻고 더 어려운 단계에서 다시 시작하는 모바일 방치형 게임이다.

이 문서는 현재 프로토타입에 구현된 내용을 기준으로 한다. 모든 수치는 `Assets/Scripts/Balance.cs` 한 곳에 있다.

| 항목 | v0.2 | v1.0 |

| 추가된 기능 | — | 저장/불러오기, 데이터 초기화, 타이틀 화면, 게임 방법, 설정(소리 크기, 종료), 농기계 쿨타임 게이지, 배경음악, 디버그 버튼 |

## 1. 핵심 루프

1. 밭 48칸(가로 6 × 세로 8)에 작물이 자란다.
2. 낫질과 농기계로 작물 체력을 깎는다.
3. 작물을 쓰러뜨릴 때마다 **코인**을 얻는다.
4. 밭을 모두 비우면 **클리어 보너스(코인)** 와 **명성**을 받고, 0.5초 뒤 같은 밭이 다시 자란다.
5. 코인으로 낫과 농기계를 사고 강화한다.
6. 명성으로 다음 밭을 열어, 더 단단하지만 보상이 큰 작물로 옮긴다.
7. 옥수수 밭을 연 뒤 명성을 충분히 모으면 **새 농장을 개척**한다. 진행은 초기화되지만 **황금 씨앗**으로 영구 강화를 얻는다.

```
작물 수확 → 코인 → 낫·농기계 강화 ─┐
     ↑                              │
     └──── 더 빨리 수확 ←───────────┘
밭 클리어 → 명성 → 다음 밭 열기 (체력·보상 ↑)
명성 충분 → 새 농장 개척 → 황금 씨앗 → 영구 강화 → 다음 판이 더 빠름
```

## 2. 화면 구성

세로 화면, 기준 해상도 1080×1920. 화면 비율이 달라도 전체가 보이도록 맞춘다.

| 영역 | 내용 |
|---|---|
| 상단 | 코인, 명성(★), **밭 이름 버튼**(누르면 밭 이동 창. 다음 밭을 열 수 있으면 깜빡임), 남은 작물 진행 바 |
| 중앙 | 6×8 밭. 피해 입은 작물에만 체력 바. 현재 타겟은 노란 테두리 |
| 하단 가운데 | 수확 버튼 (크게, 현재 낫 피해 표시) |
| 하단 왼쪽 | 보유 농기계 쿨타임 게이지 (기체당 원 1개, 종류별 최대 10개) |
| 하단 오른쪽 | 상점 버튼, 설정 버튼 |
| 왼쪽 아래 구석 | DBG 버튼 (테스트용, 출시 때 끔) |

**창** (한 번에 하나만 열림): 상점(강화) · 개척 · 밭 이동 · 설정 · 게임 방법

## 3. 밭과 작물

| 밭 | 작물 체력 | 작물 1개 보상 | 클리어 명성 | 여는 비용 (명성) |
|---|---|---|---|---|
| 밀 | 1 | 1 | ★1 | 처음부터 열림 |
| 벼 | 5 | 4 | ★2 | ★5 |
| 옥수수 | 25 | 18 | ★4 | ★20 |
| 당근 | 125 | 75 | ★8 | ★60 |
| 호박 | 625 | 320 | ★16 | ★200 |

- 체력과 보상에는 개척 단계와 영구 강화 배율이 곱해진다 (8장).
- 클리어 보너스: 이번 밭에서 번 코인의 50% (영구 강화로 증가).
- 체력·피해·보상은 소수로 계산한다. 화면에는 100 미만은 소수 1자리, 1000 이상은 K/M/B로 표기한다.
- 작물 외형은 체력에 따라 3단계로 바뀐다: 멀쩡함 → 기울어짐 → 쓰러지기 직전(더 기울고 어두워짐).

**수치 설계 의도**: 위 밭일수록 체력 1당 보상은 조금 낮다. 대신 강해질수록 아래 밭에서는 **초과 피해**(체력 1짜리에 피해 10)가 낭비되므로, 충분히 강해지면 위 밭이 더 이득이 된다.

## 4. 직접 수확

| 항목 | 규칙 |
|---|---|
| 수확 버튼 | 누르는 순간 낫질 1회. 0.3초 넘게 누르고 있으면 초당 4회 반복 |
| 작물 직접 탭 | 그 작물이 현재 타겟이 되고 낫질 1회 |
| 멀티 터치 | 손가락마다 누르는 순간 1회씩 |
| 타겟 | 한 작물이 쓰러질 때까지 같은 작물을 벤다. 쓰러지면(농기계에 쓰러진 경우 포함) 남은 작물 중 무작위로 다음 타겟 |
| 피해 | 기본 1. 낫 강화와 영구 강화로 증가. 초과 피해는 사라진다 |

## 5. 농기계

| 장비 | 쿨타임 | 범위 | 피해 | 첫 구매가 |
|---|---|---|---|---|
| 예초기 | 1.5초 | 기준 칸을 가운데로 한 3칸 (가장자리면 안쪽으로 밀어 항상 3칸) | 1 | 10 코인 |
| 콤바인 | 4초 | 한 줄 전체 (가로 6칸 또는 세로 8칸) | 5 | 500 코인 |

- 작동: 쿨타임이 끝나면 남은 작물 하나를 무작위로 기준 삼고, 가로/세로를 무작위로 골라 경로 위 작물에 한꺼번에 피해를 준다.
- 종류별 최대 10대. 여러 대의 쿨타임은 자동으로 엇갈리게 시작한다.
- 낫과 농기계는 동시에 작동한다. 이미 쓰러진 작물에는 피해가 없다.
- 밭이 다시 자라는 0.5초 동안(밭 이동, 개척 포함)은 쿨타임이 멈춘다.
- 하단 왼쪽 게이지가 위에서부터 시계 방향으로 차오르고, 작동하는 순간 톡 튄다.

## 6. 강화 (코인, 상점)

가격은 단계마다 증가율만큼 곱해지고 정수로 올림한다.

| 항목 | 효과 | 기본가 | 증가율 |
|---|---|---|---|
| 낫 강화 | 낫 피해 ×1.25 | 15 | ×1.5 |
| 농기계 구매 | 1대 추가 (종류별 최대 10대) | 장비 첫 구매가 | ×1.25 |
| 농기계 피해 강화 | 피해 ×1.2 | 예초기 25 / 콤바인 1,000 | ×1.6 |
| 농기계 쿨타임 단축 | 쿨타임 ×0.95, 최대 10단계 (약 −40%) | 예초기 30 / 콤바인 1,500 | ×1.8 |
| 정밀 조준 | 살아 있는 작물이 가장 많은 경로를 고름 | 예초기 200 / 콤바인 5,000 | 1회 구매 |

농기계 강화는 해당 종류 전체에 적용되고, 1대 이상 있어야 살 수 있다.

## 7. 밭 이동과 명성

| 항목 | 규칙 |
|---|---|
| 명성 | 밭을 **모두 비웠을 때만** 얻는다 (작물 하나하나에서는 얻지 않음) |
| 밭 열기 | 명성을 써서 다음 밭을 순서대로 하나씩 연다. 열면 바로 이동 |
| 이동 | 한 번 연 밭은 언제든 무료로 오간다 |
| 이동할 때 | 지금 밭의 남은 작물은 보상 없이 사라지고 0.5초 뒤 새 밭이 자란다 |
| 유지 | 코인, 명성, 농기계, 모든 강화 |
| 밭 이동 창 | 연 밭과 다음 밭까지만 이름과 수치를 보여주고, 그 뒤는 "??? 밭"으로 가린다 |

## 8. 새 농장 개척 (환생)

지금 농장을 팔고 더 척박한 땅에서 다시 시작한다. 진행을 잃는 대신 영구 재화인 **황금 씨앗**을 얻는다.

| 항목 | 규칙 |
|---|---|
| 열리는 조건 | 옥수수 밭을 처음 열면 상점에 **개척 탭**이 생긴다. 한 번 열리면 계속 열려 있다 |
| 필요 명성 | `30 × 2^(단계−1)` — 30, 60, 120, 240 … |
| 보상 | 황금 씨앗 = `floor(0.1 × √이번 판에 번 코인)`. 개척 탭에 항상 미리 표시 |
| 실행 | 실수 방지로 버튼을 두 번 눌러야 한다 |
| 초기화 | 코인, 명성, 연 밭(밀만 남음), 농기계, 낫·농기계 강화 |
| 유지 | 황금 씨앗, 영구 강화, 개척 단계, 최고 기록 |
| 개척 단계 | 1단계에서 시작. 개척할 때마다 +1. 단계마다 작물 체력 ×1.5, 보상 ×2 |

**영구 강화 (황금 씨앗)**

| 이름 | 효과 | 기본가 | 증가율 | 최대 |
|---|---|---|---|---|
| 풍년 | 모든 수확 보상 +25% | 1 | ×1.6 | 없음 |
| 명장의 낫 | 낫 피해 +25% | 1 | ×1.6 | 없음 |
| 농기계 할인 | 농기계 구매가 −5% (곱연산) | 2 | ×1.8 | 10 |
| 깔끔한 수확 | 클리어 보너스 +25%p | 1 | ×1.6 | 없음 |
| 물려받은 예초기 | 개척 직후 예초기 1대 보유 | 3 | — | 1 |

## 9. 저장과 설정

| 항목 | 규칙 |
|---|---|
| 저장 파일 | `Application.persistentDataPath/save.json` (JSON) |
| 자동 저장 | 10초마다, 앱을 내리거나 끌 때, 밭을 열 때, 개척할 때 |
| 저장하지 않는 것 | 밭에 남은 작물, 농기계 쿨타임 진행도 (불러오면 새로 시작) |
| 깨진 저장 | 새 게임으로 시작하고 깨진 파일은 `save.json.bad`로 남긴다 |
| 설정 창 | 배경음악·효과음 크기, 지금 저장, 게임 방법, 저장하고 종료, 데이터 초기화(두 번 눌러 확정) |
| 소리 설정 | 게임 진행과 따로 저장. 데이터 초기화해도 유지. 기본값 배경음악 50%, 효과음 100% |
| 종료 | 저장 후 종료. 에디터에서는 Play 정지. iOS는 앱 스스로 종료할 수 없어 동작하지 않음 |

## 10. 타이틀과 게임 방법

- **타이틀**: 실행하면 가장 먼저 보인다. 아이콘 그림, 게임 이름, 시작 버튼(저장이 있으면 "이어하기", 없으면 "시작하기"), 게임 방법 버튼. 떠 있는 동안 게임이 멈춘다.
- **게임 방법**: 4쪽 — 낫으로 수확하기 / 농기계 들이기 / 새 밭으로 이동 / 새 농장 개척. 처음 실행하면 시작 직후 자동으로 열린다. 열려 있는 동안 게임이 멈춘다.

## 부록: 코드 구조

화면 전체를 코드로 만든다. `MainScene`에서 Play를 누르면 `Bootstrap`이 모든 오브젝트를 생성한다.

| 파일 | 역할 |
|---|---|
| `Balance.cs` | 모든 수치 |
| `Game.cs`, `Model.cs` | 게임 규칙, 상태, 저장 적용 |
| `SaveSystem.cs` | 저장 파일 |
| `Bootstrap.cs` | 화면 조립, 창 연결 |
| `FieldView.cs`, `Fx.cs` | 밭 그림, 이펙트 |
| `Hud.cs`, `MachineGauges.cs` | 상단·하단 UI, 쿨타임 게이지 |
| `ShopPanel.cs`, `PrestigePanel.cs`, `FieldPanel.cs`, `SettingsPanel.cs` | 각 창 |
| `TitleScreen.cs`, `GuidePanel.cs` | 타이틀, 게임 방법 |
| `Sfx.cs`, `Music.cs` | 효과음 합성, 배경음악, 소리 설정 |
| `Hotkeys.cs`, `DebugPanel.cs` | PC 단축키, 디버그 버튼 |
| `Ui.cs`, `Num.cs` | UI 도우미, 숫자 표기 |
